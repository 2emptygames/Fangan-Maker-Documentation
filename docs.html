>fangan maker: documentation

>introduction

>what is fangan maker?

Fangan Maker is an external application compatible with RPG Maker MV and RPG Maker MZ that allows the user to make playable Fanganronpa projects without the need to code, as long as you have the assets and the script completed. The aim of the tool is to make Fangan development much more accesible for those that struggle through programming, as well as reduce development time substantially for those that are more experienced with coding.


>frequently asked questions

>when will fangan maker release?

Fangan Maker will release its 1.0 version sometime in early 2027.


>do i need to own rpg maker mv/mz to use fangan maker?

Yes. Fangan Maker requires the user to own a legal copy of RPG Maker MV or RPG Maker MZ.


>does fangan maker work with [other rpg maker version]?

No. Fangan Maker is only compatible with RPG Maker MV and RPG Maker MZ. Compatibility with RPG Maker U2U will be considered once it releases, but it cannot be confirmed until then.


>can fangan maker be used for projects that aren't fanganronpas?

Yes, but Fangan Maker is built to cater to the creation of fanganronpas, so you might find yourself not using most features.


>can fangan maker be used for commercial projects?

Yes, but different regulations apply. Please check the terms of use section for more information.


>will you make fangan maker for other engines?

No. Development of Fangan Maker will remain exclusive to RPG Maker. You can find similar tools for other engines on the alternatives section.


>can fangan maker be used in already existing projects?

Yes. You might run into compatibility issues, so it's recommended to run tests on a security copy of your project. If you have already coded minigames for your project, it's suggested to refrain from using Fangan Maker's minigame functionalities.


>will [insert minigame/feature] be included in fangan maker?

No future features are confirmed as of now.

>getting started with fangan maker

>how to install fangan maker?

To install Fangan Maker, you must first download it from either the itch.io page or the Gamejolt page. Open the resulting folder and you will find a file labeled "Fangan Maker Setup.exe". Run this file, wait for the process to finish and Fangan Maker will be installed in your computer.

Fangan Maker also has a portable option for those that prefer it. Instead of running the setup file, go into the folder labeled "win-unpacked" and run the file labeled "Fangan Maker.exe".

Instructions for devices using Linux and MacOS will be added at a later date.


>how to open a project in fangan maker?

To open a project in Fangan Maker you must first click the "Select Project" button. This will open your computer's documents folder for you, and you must look for the folder that contains your project. Typically, RPG Maker MV projects are stored in a folder labeled "Games", while RPG Maker MZ projects are stored in a folder labeled "RMMZ".

Once you've selected the desired project folder, press the enter key on your keyboard and you will have succesfully selected a project.

You can only open projects in Fangan Maker's index page.


>how to change projects in fangan maker?

To change projects in Fangan Maker you must first click the "Select Project" button. This will open your computer's documents folder for you, and you must look for the folder that contains your project. Typically, RPG Maker MV projects are stored in a folder labeled "Games", while RPG Maker MZ projects are stored in a folder labeled "RMMZ".

Once you've selected the desired project folder, press the enter key on your keyboard and you will have succesfully changed projects.

>how to find your event id in fangan maker?

When using Fangan Maker, you will notice that you will be asked to enter an "event ID" in multiple places, and you might ask yourself something along the lines of "What exactly is an event ID? Where do I find an event ID?".

To understand event IDs, we first need to know what an event is: An event in RPG Maker is a core mechanic used to serve either the purpose of interactive characters or items, as static or animated objects, or as a way to create scripted events or cutscenes in games. Put more simply, an event is where RPG Maker code is stored. It's visually represented by a translucent gray square with a white outline.

An event in RPG Maker MV.

Fangan Maker will write your code for you, but it needs to do so inside of an event. Each event in a particular map has its own unique number for indentification, and that number is what is known as an event ID. Event IDs go from 1 to 999. You cannot change the event ID of an event.

Location of the event ID inside of an event in RPG Maker MV.

To find out what your event ID is, you need to open RPG Maker and double click on your event to open the event page. Once the event page is open, please refer to the upper left corner of it, where you'll see text that reads "ID:XXX". That number is the event ID Fangan Maker is asking you to input.

>setup section

In the Setup section of Fangan Maker, you will be able to setup Fangan Maker to adapt to the needs of your project. It consists of nine subsections.

>character setup

Character setup allows you to manage the character data for each of your projects. This character data is stored on a database Fangan Maker creates for each of your projects. It can be found on your project's "data" folder, labeled "project.json". Please read on the available options below.


>create character

To create a character, you must fill out the entire section before clicking the "Add Character" button.

  • Character Name:

    • Your character's name. When you're writing your script, this is the name you must write if you want your character to be the one speaking.

    Please note that character names are case sensitive. For example, "Makoto Naegi" and "makoto naegi" would be interpreted as two different characters.

  • Common Event Name:

    • This is the name the Common Event associated to your character in RPG Maker will have.

  • Sprite X Coordinate:

    • This number dictates the position of the character's sprites on the X coordinate, meaning its horizontal position. The default value places their sprites on the center of a 1248px x 720px screen.

  • Sprite Y Coordinate:

    • This number dictates the position of the character's sprites on the Y coordinate, meaning its vertical position. The default value places their sprites on the center of a 1248px x 720px screen.

  • Sprite X Scale:

    • This number dictates the scale of the character's sprites on the X coordinate, meaning how big it is horizontally. If you want the sprites to be proportional, this number should be equal to the Sprite Y Scale.

  • Sprite Y Scale:

    • This number dictates the scale of the character's sprites on the Y coordinate, meaning how big it is vertically. If you want the sprites to be proportional, this number should be equal to the Sprite X Scale.

  • Textbox Image Layer:

    • This number dictates the layer your textbox image will be on. The bigger the number, the more images it can have below it. This number must be shared by all characters. The default value is suggested for people without RPG Maker experience, as it leaves enough room for flexibility.

  • Textbox Image:

    • Your character's textbox image, selected from your computer. This image must be stored in "img/pictures".

    Please note that this image's size must match your game's resolution. For example, if your game's resolution is "1920px x 1080px", your textbox image size must also be "1920px x 1080px".

  • Dialogue SFX:

    • A toggle allowing you to add a Dialogue SFX sound everytime your character talks.

    When selected, it will show a list featuring all the SFX you have currently created, You must select the one you want to add.


>delete character

To delete a character, you must fill out the entire section before clicking the "Delete Character" button.

  • Character Name:

    • A list featuring all the characters you have currently created. You must select the one you want to delete.


>edit character

To edit a character, you must choose the character you want to edit, change the value for the option you want to edit and click the corresponding button. The following options are available to edit:

  • Character Name

  • Common Event Name

  • Sprite X Coordinate

  • Sprite Y Coordinate

  • Sprite X Scale

  • Sprite Y Scale

  • Textbox Image


>sprite setup

Sprite setup allows you to manage the sprite data for each of your projects. Sprites are associated with characters, so you must create at least one character before sprite setup is functional. This sprite data is stored on a database Fangan Maker creates for each of your projects. It can be found on your project's "data" folder, labeled "project.json". Please read on the available options below.


>add sprite individually

To add a sprite individually, you must fill out the entire section before clicking the "Add Sprite" button.


  • Character Name:

    • A list featuring all the characters you have currently created. You must select the character the sprite you want to add belongs to.

  • Sprite Image:

    • Your sprite image, selected from your computer. This image must be stored in "img/pictures".

  • Script Name:

    • Your sprite's name. When writing the script, this is the name you must write for your sprite to show on screen.

    Please note that script names are case sensitive. For example, "Happy" and "happy" would be interpreted as two different sprites.

>add sprites in bulk

To add sprites in bulk, you must fill out the entire section before clicking the "Add Sprites" button.


  • Character Name:

    • A list featuring all the characters you have currently created. You must select the character the sprites you want to add belong to.

  • Sprite Images:

    • Your sprite images, selected from your computer. You can select multiple images. These images must be stored in "img/pictures".

    Please note that, when adding sprites in bulk, the Script Name for each of those sprites will be the same as their name on your computer. For example, if your file name is "ThisIsMySprite.png", your script name will be "ThisIsMySprite".

>delete sprite

To delete a sprite, you must fill out the entire section before clicking the "Delete Sprite" button.


  • Character Name:

    • A list featuring all the characters you have currently created. You must select the character the sprite you want to delete belongs to.

  • Sprite Name:

    • A list featuring all the sprites you have currently created for the character you selected. You must select the one you want to delete.

>free time event setup

Free Time Event setup allows you to manage Free Time Events for each of your projects. Free Time Events are associated with characters, so you must create at least one character before Free Time Event setup is functional. The Free Time Event data is stored on a database Fangan Maker creates for each of your projects. It can be found on your project's "data" folder, labeled "project.json". Please read on the available options below.


>create free time event (☆)

To create a Free Time Event, you must fill the following sections before clicking the "Create Free Time Event" button:


  • Create Free Time Event

  • Sprite Customization

  • Volume Customization

  • Text Customization

These mandatory sections have been marked using the (☆) symbol both in the documentation and inside of Fangan Maker for ease of access.


  • Select Character:

    • A list featuring all the characters you have currently created. You must select the one the Free Time Event you want to add belongs to.

  • Free Time Event Name:

    • Your Free Time Event's name.

  • Free Time Event Script:

    • Your Free Time Event's script, selected from your computer. Your script format must be "txt". To learn how to write scripts for Fangan Maker, please refer to this section.

>sprite customization (☆)

Sprite customization allows you to change properties associated with the sprites present in your script. This section must be filled out before clicking the "Create Free Time Event" button.


  • Sprite Position:

    • The position your sprite will be in for this Free Time Event.

  • Sprite Image Layer:

    • This number dictates the layer your sprite image will be on. This number must be lower than the textbox image number, or the sprites will appear above the textbox. This number will be shared by all characters. The default value is suggested for people without RPG Maker experience.

>volume customization (☆)

Volume customization allows you to change properties associated with the volume of the audio present in your script, whether it's music, voicelines or SFX. This section must be filled out before clicking the "Create Free Time Event" button.


  • Voiceline Volume:

    • The volume your voicelines will have for this Free Time Event.

  • Music Volume:

    • The volume you music will have for this Free Time Event.

  • SFX Volume:

    • The volume your SFX will have for this Free Time Event.

>text customization (☆)

Text customization allows you to change properties associated with the text present in your script. This section must be filled out before clicking the "Create Free Time Event" button.


  • Text Position:

    • The position your text will appear on screen for this Free Time Event.

>delete free time event

To delete a Free Time Event, you must fill out the entire section before clicking the "Delete Free Time Event" button.


  • Character Name:

    • A list featuring all the characters you have currently created. You must select the character the Free Time Events you want to delete belongs to.
