>what is fangan maker?

Fangan Maker is an external application compatible with RPG Maker MV and RPG Maker MZ that allows the user to make playable Fanganronpa projects without the need to code, as long as you have the assets and the script completed. The aim of the tool is to make Fangan development much more accesible for those that struggle through programming, as well as reduce development time substancially for those that are more experienced with coding.
