>fangan maker: alternative tools

Fangan Maker might not be the tool for everybody, so in this section you can find some alternative tools for developing fanganronpas that might fit your needs better. If you are working on a fanganronpa tool and would like to have it featured in this page, please contact us through this form.

>Danganmake

Danganmake is a 100% free software that lets you create your very own Danganronpa. It was developed so the community can build their own stories with custom characters, situations, and ending, and then share them with the whole world!

>social media

>DREditor

DREditor is a Unity Package Library that allows the recreation of gameplay core to the original danganronpa series without having to code! From Investigations to Non-Stop Debate, DREditor has everything you need across over 70+ Modular packages!

Notably used in: Project: Eden's Garden, Kill/Cure: Beautiful Vice, The Uzujigoku Massacre
